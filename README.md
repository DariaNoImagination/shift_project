# Сервис бронирования переговорных комнат

## Описание 

В системе есть несколько комнат, каждая из которых имеет заранее заданные
временные слоты (например, «09:00–11:00», «13:00–16:00» и т.п.).
Помимо комнат в системе
есть сотрудники и администраторы. Сотрудники могут просматривать доступность всех комнат
на конкретную дату, создавать и отменять свои бронирования (доступ к чужим броням
запрещён). Администраторы, дополнительно к возможностям сотрудников, могут отменять
любые бронирования.


## Стек использованных технологий
**Backend:**
   - Python - основной язык программирования

   - FastAPI - веб-фреймворк

   - PostgreSQL - основная база данных

**Frontend:**
   - HTML/CSS - разметка и стили

   - JavaScript  - интерактивные элементы


## Как развернуть проект
### 1. Виртуальное окружение

Перед началом работы необходимо создать и активировать виртуальное окружение Python.  

1. **Создайте виртуальное окружение (в папке проекта):**
   ```bash
   python3 -m venv venv
   ```

   После этого появится папка `venv`, где будут храниться зависимости проекта.

2. **Активируйте окружение:**

    - **Windows (PowerShell):**
      ```bash
      venv\Scripts\Activate.ps1
      ```
    - **Windows (cmd):**
      ```bash
      venv\Scripts\activate
      ```
    - **Linux/Mac:**
      ```bash
      source venv/bin/activate
      ```

### 2. Запуск PostgreSQL

```bash
docker compose up -d
```

`-d` значит `detach`, то есть контейнер продолжит работать в фоне. Чтобы его остановить, надо будет ввести

```bash
docker compose down
```
Если возникает ошибка "permission denied while trying to connect to the Docker daemon socket", то может потребоваться добавить `sudo` перед командой.
